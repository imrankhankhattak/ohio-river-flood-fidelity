# ohio-river-flood-fidelity

Geometric Fidelity vs. Flood Prediction Accuracy on the Ohio River

This repository contains code and data for a study analyzing how terrain representation fidelity affects flood prediction accuracy.

## Project Overview
- **Goal:** Determine optimal terrain representation for flood modeling
- **Site:** Louisville, KY on Ohio River
- **Event:** May 2018 flood
- **Fidelity Levels:** L0 (global DEM) → L5 (DTM + bathymetry)

## Setup
1. Clone this repository
2. Install requirements: `pip install -r requirements.txt`
3. Run notebooks in order: `01_data_download.ipynb` → `02_datum_check.ipynb` → ...

## Data
All data is available on Kaggle: [ohio-river-data-v1](https://kaggle.com/datasets/yourusername/ohio-river-data-v1)
